# typst-upstream

The tools that read upstream Typst for `avenger-typst-label`: `upstream_diff.py` compares the
ported files with upstream's, and `references/` generates the frame and math references.
[`avenger-typst-label/UPSTREAM.md`](../../avenger-typst-label/UPSTREAM.md) describes them, and
the procedure for a new Typst release.
